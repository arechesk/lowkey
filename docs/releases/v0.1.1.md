# lowkey 0.1.1

- Control one saved site with the bundled `lowkeyctl`: open, hide, toggle or return to its start page without bringing an unrelated site forward.
- Inspect controls, wait, click, fill fields, select an option or attach a file on an already-open page. Page actions stay on the saved origin; uploads are limited to one file of up to 8 MiB.
- Click the running app in the Dock to show the address panel. An empty panel lists only configured sites; typing also searches submitted addresses.
