# lowkey 0.1.2

## Save pages as PDF

- Choose **Save as PDF…** in a page's context menu or **View → Save as PDF…** (Command-Shift-S).
- Run `lowkeyctl ALIAS save-pdf PATH.pdf` to save an open saved-site document without a print dialog. Relative paths and `~` are supported. The command never overwrites an existing file.
- Export uses WebKit's A4 print layout and print styles for the entire current document, not just the visible viewport. It does not load lazy content or expand virtualized lists.
- Ting's native micro-app step supports `action: save-pdf` with a templated `file:` path starting with Ting 0.7.16.

## Page-colored window strips

- Tint is the default appearance mode. The window strip follows the site's theme color, falling back to its background, and preserves its previous tint while the page loads.
- Tint changes animate briefly; strip icons adapt for contrast. The address prompt and accent line retain the chosen palette.
- Existing Page configurations migrate once to Tint. Page, System, Light and Dark remain available; lowkey does not recolor website content.

## Distribution

Universal macOS ZIP for Apple Silicon and Intel, Developer ID signed, notarized and stapled, with SHA-256 checksums. No automatic updater or Homebrew support.
