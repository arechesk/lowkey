# lowkey 0.1.0

The first public binary release: a Developer ID signed, notarized and stapled
universal ZIP for Apple Silicon and Intel. Install lowkey.app in /Applications.
The public product name is always lowercase: lowkey.

- A macOS browser using AppKit and system WebKit, without tabs or a permanent
  address bar. Saved sites open by alias, each in its own persistent profile.
- Saved-site windows keep their size and position. Hide a site without closing
  its page, or close it while retaining its sign-in state.
- Command-L opens the address/alias prompt; Command-Shift-L explicitly opens an
  address in the current window and profile, including sign-in/popup windows.
- `lowkey://alias/open` and `lowkey://alias/toggle` integrate with launchers.
  `lowkey://*/toggle` toggles the existing saved-site windows together.
- Shared BobukKit picker UI with equal-width alias badges, centered text,
  consistent row highlighting, a rounded frame and wrapping shortcut hints.
- Address suggestions from saved sites and submitted-input history, with
  Russian/Ukrainian ↔ US keyboard-layout matching.
- Page-aware light/dark window chrome, configurable palettes and accent colors.
- Basic downloads, uploads, JavaScript dialogs and HTTP authentication.

## Requirements and limits

macOS 14 or later. Universal Apple Silicon/Intel binary preparation is supported.
Build from source with Swift 6.2 / Xcode 26 or later. No automatic updater,
extensions or password-manager integration. Some identity providers reject
embedded browsers; complex OAuth flows are not guaranteed to work.

No automatic updater or Homebrew cask is included. To update, quit lowkey and
replace only the app; profiles, settings and history are retained.
Settings, website-data profiles and input history stay on the Mac. See README
and SECURITY.md for storage, permissions and removal instructions.
